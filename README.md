# hxwl-03 岩土钻孔编录

钻探回次登记与取样移交的闭环记录面板：回次逐段承接、采取率管控、原状样归回次、交班冻结与更正副本，全部数据本地落盘。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 业务闭环

- **回次登记**：每回次填写起止深度、回次进尺（按起止自动计算）、主要岩性与岩心采取长度；后一回次起点强制承接前一回次终点（首回次自孔口 0.00m 起）。
- **采取率管控**：采取率低于 65% 的回次不予登记，井段自动列入「缺失井段」；补钻合格重新登记后，被覆盖的缺失井段自动闭合。
- **取样登记**：原状样只能落在同一回次起止深度内，跨回次取样被拒绝。
- **交班移交**：勾选待移交样品办理交班；同孔同深存在重复取样（含与已冻结样品重复）时阻止移交并列出冲突。交班后样品冻结，不可删改。
- **更正副本**：冻结样品更正时保留原记录，新建带必填原因的冻结副本，原记录标记「已更正」并退出查重；副本可继续链式更正。
- **落盘**：回次、样品、交班、缺失井段与副本关系实时写入 localStorage（键 `hxwl03.drilling.v1`），刷新或重新进入页面后完整恢复；支持导出 JSON 与一键重置演示数据。

## 代码结构

- `src/lib/drilling.ts` — 领域模型与全部业务规则（纯函数，含落盘与演示数据）
- `src/App.tsx` — 页面与交互
- `src/styles.css` — 样式
