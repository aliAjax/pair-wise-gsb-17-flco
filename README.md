# hxwl-03 岩土钻孔编录

钻探回次连续承接、采取率门槛、原状样同回次约束与交班冻结的现场编录闭环。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 业务闭环

- **回次登记**：每个回次填写起止深度、回次进尺、主要岩性与采取率；后一回次起点自动承接（并校验）前一回次终点，进尺必须等于起止深度之差。
- **采取率门槛**：采取率低于下限（默认 65%）不得登记；页面实时列出 `[孔口, 设计孔深]` 内未被覆盖的缺失井段。
- **取样约束**：原状样深度区间必须完整落在同一回次内（跨回次边界或缺失井段均被拒绝）；同孔同深重复取样会阻止交班移交，须先删除或更正。
- **交班冻结**：交班生成移交批次（交班人/接班人/时间），批次内样品转为冻结，不可删除或直改。
- **更正副本**：冻结样品的更正保留原记录，新建带更正原因的副本并重新走移交流程；副本与原记录通过 `originId` / `supersededBy` 双向关联，删除待移交副本可恢复原记录现行状态。

## 数据落盘

- 所有变更实时写入 `localStorage`（键：`hxwl03-borehole-log-v1`），重新进入页面后回次、样品、交班批次与副本关系完整恢复。
- 工具栏支持导出 JSON 存档、导入备份恢复、重置为示例数据。

## 目录结构

- `src/types.ts` — 钻孔 / 回次 / 样品 / 交班数据模型
- `src/domain.ts` — 纯函数业务规则（承接校验、缺失井段、同回次约束、重复检测、移交校验）
- `src/store.ts` — 种子数据、localStorage 读写、纯函数式变更
- `src/components/` — 回次登记、取样登记、交班移交三个业务区块
